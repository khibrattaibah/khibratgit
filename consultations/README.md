# استشارة خبرات

نسخة تشغيلية أولية لمبادرة الاستشارات الأسبوعية المجانية لمكتب خبرات طيبة للبحوث والدراسات.

## البنية
- Static HTML/CSS/JS: قابلة للنشر على Cloudflare Pages أو GitHub Pages.
- Supabase: PostgreSQL + Auth + RLS.
- Luma: للحجز بعد قبول الطلب فقط.
- Google Calendar/Meet: للمواعيد والاجتماعات.

## التشغيل
1. أنشئ مشروعًا مجانيًا في Supabase.
2. من SQL Editor نفّذ الملف `supabase/schema.sql`.
3. من Project Settings > API انسخ Project URL و anon public key إلى `config.js`.
4. من Authentication أنشئ مستخدمًا إداريًا واحدًا أو أكثر.
5. افتح `admin.html` وسجّل الدخول.
6. للنشر على Cloudflare Pages اختر مجلد `consultations` كمصدر للموقع أو انقل محتواه إلى مستودع مستقل لاحقًا.

## الأمان
لا تضع Service Role Key في الواجهة مطلقًا. الواجهة تستخدم anon key فقط، والحماية تعتمد على RLS. الزائر يستطيع الإرسال فقط، ولا يستطيع قراءة الطلبات. القراءة والتعديل متاحان للمستخدمين المسجلين.

## مسار العمل
طلب جديد -> مراجعة -> قبول/انتظار/اعتذار -> إضافة رابط Luma -> حجز -> جلسة Google Meet -> إغلاق الطلب وقياس الأثر.

## ملاحظة
رابط Luma لا يُنشر في الواجهة العامة. يضاف داخل لوحة الإدارة لكل حالة مقبولة ثم يرسل للمستفيد عبر البريد/وسيلة التواصل المعتمدة.
