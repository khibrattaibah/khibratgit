# منهج التثبت للمحتوى والأمثلة

## سجل الدليل

لكل ادعاء قابل للتحقق، سجل النص المحدد، والمصدر الأولي إن أمكن، والمؤلف أو الجهة، والإصدار أو التاريخ، والرابط أو الصفحة، وتاريخ الاطلاع للمصادر المتغيرة. ميز النص الأصلي والاقتباس الدقيق عن التلخيص والترجمة والاستنتاج. لا تجعل إجابة النموذج أو اقتباسًا مجهول الأصل مصدرًا مستقلًا.

## سير المراجعة

1. حدد السؤال ونطاقه وما الذي سيعد دليلًا كافيًا قبل جمع المواد.
2. تحقق من صحة النص، وسياقه، وحقوق استخدامه، ثم قارنه بمصدر مستقل عند تعارض الأدلة أو ارتفاع أثر الخطأ.
3. وثق التحويلات، ومنها OCR والترجمة والتلخيص، مع نسخة المصدر وحدود الدقة وأمثلة الأخطاء المكتشفة.
4. افصل الملاحظة عن التفسير والحكم؛ اذكر عدم اليقين والخلاف العلمي بإنصاف. في النص القرآني، يبدأ المعنى من النص وسياقه ومصادر التفسير المعتبرة، ثم يراجع المختص الاستنتاج قبل نشره؛ لا تُسقط فرضية تقنية على الآية.
5. يراجع مختص المجال الادعاءات الحساسة، ويثبت من راجع ومتى وما القرار. افتح مسارًا لتصحيح الخطأ أو سحب الناتج مع بيان النسخة المتأثرة.

لا يعني وجود دراسة محكمة أن كل منتج أو تلخيص مشتق منها محكّم. لا تختلق مرجعًا أو قياسًا أو موافقة، ولا تنشر مادة طرف ثالث إذا تعذر إثبات حق إعادة استخدامها.
