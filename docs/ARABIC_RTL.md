# ضوابط العربية واتجاه العرض

- العربية لغة الواجهة والتوثيق الأساسية؛ اكتب بلغة سليمة وواضحة، وحافظ على رسم الآيات وعلاماتها بعد المطابقة مع مصدر موثوق.
- عيّن `lang="ar" dir="rtl"` على الحاوية العربية في HTML، و`lang="en" dir="ltr"` للمقاطع الإنجليزية المستقلة. اختبر عرض GitHub Markdown لأن دعم الاتجاه يختلف بين العارضات.
- اعزل المعرفات البرمجية والروابط والبريد وDOI والأوامر داخل عناصر أو تنسيق LTR مناسب. لا تعكس تسلسل أحرفها يدويًا ولا تدرج محارف تحكم خفية لإصلاح شكل عارض واحد.
- اجعل المحاذاة والهوامش منطقية بحسب اتجاه الكتابة (`start`/`end` وخصائص CSS المنطقية)، مع بقاء ترتيب القراءة والتنقل بلوحة المفاتيح مفهومًا.
- اختبر العربية مع الإنجليزية والأرقام والأقواس والروابط في العناوين والجداول والنماذج والجوال؛ تحقق من قارئ الشاشة، وإمكانية نسخ النص والبحث فيه، وعدم قص التشكيل.
- تحفظ الملفات النصية بترميز UTF-8. استخدم أسماء ملفات مستقرة للأدوات وراجع نتيجة النسخ والتصدير إلى PDF حتى لا ينقلب اتجاه النص.
